# Materiais para divulgação após aprovação humana

**WhatsApp** — Quer organizar uma tarefa com IA? O APEX reúne 11 especialidades com instruções reutilizáveis. Escolha uma delas, experimente com um pedido fictício e confira o resultado com um checklist.

**Professores e pesquisadores** — Experimente o APEX para planejar uma aula ou organizar a revisão de um artigo. Peça uma lista de afirmações, evidências disponíveis e questões para revisão humana. Use dados públicos ou fictícios e confira pessoalmente as referências.

**LinkedIn** — O Apex Elite Framework, de Matheus Florindo, oferece instruções abertas para planejar projetos e revisar entregas. O catálogo reúne 11 skills para tarefas como software, ciência e edição. Quem usa Python também pode gerar planos e checklists localmente. Convidamos a comunidade a testar o início rápido e relatar o primeiro passo que ficou pouco claro.

**Apresentação curta** — O APEX ajuda a escolher quem deve revisar cada parte de um trabalho, quais materiais fornecer e como avaliar a entrega. A distribuição usa licença Apache 2.0.

## Tutorial em três passos

1. Abra o [catálogo](SKILLS.md) e escolha a especialidade correspondente ao seu objetivo.
2. Siga o [início rápido](QUICK_START.pt-BR.md) para fornecer as instruções ao assistente. Experimente “Organize uma aula de 30 minutos sobre cores para iniciantes”.
3. Confira duração, materiais e adequação à turma. Peça ajustes para cada requisito ausente.
